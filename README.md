## 👋 About Me

I'm a software engineering student at the **University of Sri Jayewardenepura**, Sri Lanka, building production systems that run at the edge. I work across the full stack — from Cloudflare Worker APIs and Astro frontends to native Android apps and CLI tooling in Rust.

My current obsession: building **VIRAMAYAK 2026**, a real-time concert ticketing platform with cryptographic QR passes, seat reservation sweepers, mobile gate scanning, bank slip OCR verification, and an operations dashboard unifying Cloudflare + Honeybadger + Resend telemetry.

- 🌏 Based in Sri Lanka
- 🎓 Studying Software Engineering at USJP
- 🔧 Full-stack + infrastructure: edge workers, D1, R2, Cloudflare Pages
- 📱 Android dev with Kotlin + Jetpack Compose
- 🛡️ Interested in zero-trust auth, HMAC signing, and edge security

---

## 🚀 Featured Project — VIRAMAYAK 2026

> **A live concert ticketing platform built entirely on Cloudflare's edge infrastructure.**

| Layer | Technology |
| :--- | :--- |
| **Frontend** | Astro, Tailwind CSS, Clerk Auth |
| **Backend** | Cloudflare Workers (TypeScript), Hono |
| **Database** | Cloudflare D1 (SQLite at the edge) |
| **Storage** | Cloudflare R2 |
| **PDF Passes** | `pdf-lib` — cryptographic HMAC QR code passes |
| **Email** | Resend (transactional delivery + Datadog log drain) |
| **Error Tracking** | Honeybadger (native Datadog event integration) |
| **Observability** | Datadog US5 — Geomap, Log Streams, Exception Triage |
| **Gate Scanner** | Native Android APK (Kotlin + Jetpack Compose, minSdk 26) |
| **Ops Dashboard** | Datadog All-in-One Mission Control Cockpit |
| **CLI Tools** | Rust (`vmk` CLI), PowerShell automation scripts |
